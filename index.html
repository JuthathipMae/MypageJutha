ชื่อเล่น : กาละแมร์ค่ะ

เหตุผลที่อยากเรียน Full stack web development

  หนูอยากพัฒนาสกิลตัวเองให้สร้างระบบที่เชื่อมทั้งหน้าบ้านกับหลังบ้านได้จริงจัง เพราะที่ผ่านมาเคยทำโปรเจกต์ IoT พวกระบบเช็คอิน RFID ร่วมกับการออกแบบหน้า GUI(่๋Java) เชื่อมกับฐานข้อมูล SQL แล้ว และเคยทำระบบแจ้งเตือนผ่าน Telegram มาแล้ว จากที่เคยเจอ bug แก้จนเหนื่อย ก็เลยอยากเรียนเพื่อต่อยอดความสามารถและสร้างเว็บหรือแอปที่มันจัดการข้อมูลได้แบบครบวงจรทั้งหน้าและหลังไปเลย จะได้เตรียมตัวเป็น Software Tester ที่เก่งรอบด้านในอนาคตค่ะ

ความคาดหวังต่อวิชานี้

  ที่คาดหวังคืออยากได้เรียนรู้ตั้งแต่การออกแบบโครงสร้างเว็บ ทั้งFront-end และ Back-end ให้มันถูกหลักเลยค่ะ แล้วก็ต้องเข้าใจการทำงานของ Database การเชื่อมต่อกับ API ด้วย จะได้เอาไปใช้กับโปรเจกต์ที่เราทำอยู่จริง ๆ ได้ อย่างเช่น เว็บแอปสำหรับแนะแนวทางในมหาลัยที่หนูกำลังพัฒนาอยู่ (GuideU 3D PIM)

จุดอ่อนที่ต้องพัฒนาและแนวทางการพัฒนา

  จุดอ่อนของหนูคือ ความไม่สม่ำเสมอในการซ้อมเขียนโค้ดค่ะ คือบางทีก็ไฟแรงบางทีก็แผ่ว แต่ตั้งใจจะแก้ด้วยการฝึกเขียนโปรแกรมวันละนิดวันละหน่อย
